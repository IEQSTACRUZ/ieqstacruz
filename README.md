# IEQ Santa Cruz - Site Oficial

Este é o repositório oficial do site da Igreja do Evangelho Quadrangular de Santa Cruz. Desenvolvido com Flask, este projeto tem como objetivo compartilhar informações, eventos e conteúdos da igreja.

## 🚀 Funcionalidades

- Página inicial com informações da igreja
- Área de contato
- Galeria de fotos
- Informações de culto e localização

## 🛠️ Tecnologias

- Python 3.x
- Flask
- HTML/CSS
- Bootstrap (frontend)
- Heroku (deploy)
